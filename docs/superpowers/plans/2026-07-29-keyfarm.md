# keyfarm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Nix flake that launches a bubblewrap-jailed, patchright-stealthed Chromium against a directory-profile of cookies, runs a plain Playwright script against it, and ships a reusable Claude command that maintains that script from natural-language instructions.

**Architecture:** Three layers — (A) a Nix flake exposing `.#browser` (manual key-farming) and `.#run` (deterministic replay) apps plus a `lib.mkApp` composition helper; (B) a bubblewrap jail wrapping `pkgs.chromium` (`--no-sandbox` inside), driven by patchright for stealth; (C) a `keyfarm-maintain.md` Claude command that keeps a `run(page)` script mirrored to a hand-written functional command. keyfarm is consumed as a flake input by downstream website-specific repos.

**Tech Stack:** Nix flakes (flake-utils, Linux-only), Node + TypeScript run via `tsx` (no build step), `patchright` (stealth Playwright fork), `bubblewrap`, `pkgs.chromium`. Tests via Node's built-in `node:test`.

## Global Constraints

- Nix flakes; systems limited to `x86_64-linux` and `aarch64-linux` (bubblewrap is Linux-only).
- TypeScript executed via `tsx` at runtime — **no compile/build step** unless a task says otherwise.
- Stealth engine is **patchright (Node), default-on, the ONLY engine.** No multi-engine abstraction.
- Browser is **`pkgs.chromium` ONLY** for now; overridable via a `browser` arg. **NEVER Google Chrome** — not as default, not as fallback. A stealth fallback may only target another *free* browser (e.g. Brave).
- Jail is **bubblewrap**: filesystem + process isolation, `--unshare-all --share-net` (network is NOT isolated), Chromium runs `--no-sandbox` inside.
- The cookies directory passed as an app argument **IS** the persistent Chromium `--user-data-dir`.
- Script contract: a module exporting `export async function run(page: Page): Promise<void>`.
- Env seam between Nix and Node: `KEYFARM_CHROMIUM` = path to the jailed-chromium wrapper binary; `KEYFARM_PROFILE` = the cookies/profile directory.
- Commits: Conventional Commits. Gitflow: work on `feature/*` off `develop`, merge with `--no-ff`.

- `flake.nix` — inputs, per-system `devShells`, `packages`, `apps.{browser,run}`, top-level `lib.mkApp`.
- `nix/jail.nix` — `mkJailed { browser }` → a `writeShellApplication` running the browser under bubblewrap.
- `nix/pw.nix` — `buildNpmPackage` producing `node_modules` + the TS sources (`keyfarm.ts`, `runner.ts`).

- `commands/keyfarm-maintain.md` — the reusable technical Claude command.
- `templates/task.ts` — scaffold script the AI maintains.
- `templates/functional-command.md` — example hand-written functional command.
- `.gitignore`, `README.md`.

```ts
import { chromium, type BrowserContext, type Page } from 'patchright';

export async function launchJailed(
  cookiesDir: string,
  opts: { headless?: boolean } = {},
): Promise<BrowserContext> {
  const executablePath = process.env.KEYFARM_CHROMIUM;
  if (!executablePath) throw new Error('KEYFARM_CHROMIUM env not set');
  // The jail wrapper binds KEYFARM_PROFILE rw at the same path patchright passes
  // as --user-data-dir, so both must agree on cookiesDir.
  process.env.KEYFARM_PROFILE = cookiesDir;
  return chromium.launchPersistentContext(cookiesDir, {
    executablePath,
    headless: opts.headless ?? true,
    // bwrap is the sandbox; disable chromium's own (can't nest in bwrap userns).
    args: ['--no-sandbox', '--disable-dev-shm-usage'],
    ignoreDefaultArgs: ['--disable-component-update'],
  });
}

export async function page(ctx: BrowserContext): Promise<Page> {
  return ctx.pages()[0] ?? (await ctx.newPage());
}
```

**Files:** Modify `pw/keyfarm.ts`.

- [ ] **Step 1: Replace `launchJailed` body with a CDP-connect implementation**

```ts
import { chromium, type BrowserContext, type Page } from 'patchright';
import { spawn } from 'node:child_process';

export async function launchJailed(
  cookiesDir: string,
  opts: { headless?: boolean } = {},
): Promise<BrowserContext> {
  const exe = process.env.KEYFARM_CHROMIUM;
  if (!exe) throw new Error('KEYFARM_CHROMIUM env not set');
  process.env.KEYFARM_PROFILE = cookiesDir;
  const port = 9000 + Math.floor(Math.random() * 1000);
  const args = [
    `--user-data-dir=${cookiesDir}`,
    `--remote-debugging-port=${port}`,
    '--remote-debugging-address=127.0.0.1',
    '--no-sandbox', '--disable-dev-shm-usage',
    '--disable-blink-features=AutomationControlled',
  ];
  if (opts.headless ?? true) args.push('--headless=new');
  const proc = spawn(exe, args, { stdio: 'ignore', detached: false });
  proc.on('exit', () => {});
  // wait for the endpoint
  const deadline = Date.now() + 15000;
  for (;;) {
    try {
      const r = await fetch(`http://127.0.0.1:${port}/json/version`);
      if (r.ok) break;
    } catch { /* not up yet */ }
    if (Date.now() > deadline) throw new Error('CDP endpoint never came up');
    await new Promise((r) => setTimeout(r, 200));
  }
  const browser = await chromium.connectOverCDP(`http://127.0.0.1:${port}`);
  return browser.contexts()[0] ?? (await browser.newContext());
}

export async function page(ctx: BrowserContext): Promise<Page> {
  return ctx.pages()[0] ?? (await ctx.newPage());
}
```

```ts
import { pathToFileURL } from 'node:url';
import { resolve } from 'node:path';
import { launchJailed, page } from './keyfarm.ts';
import type { Page } from 'patchright';

export async function runScript(cookiesDir: string, scriptPath: string): Promise<void> {
  const mod = (await import(pathToFileURL(resolve(scriptPath)).href)) as {
    run?: (p: Page) => Promise<void>;
  };
  if (typeof mod.run !== 'function') {
    throw new Error(`${scriptPath} must export async function run(page)`);
  }
  const ctx = await launchJailed(cookiesDir, { headless: process.env.KEYFARM_HEADLESS !== '0' });
  try {
    await mod.run(await page(ctx));
  } finally {
    await ctx.close();
  }
}

// CLI: runner.ts <cookies-dir> <script>
const [, , cookiesDir, scriptPath] = process.argv;
if (cookiesDir && scriptPath) {
  runScript(cookiesDir, scriptPath).catch((e) => {
    console.error(e);
    process.exit(1);
  });
}
```

## Task 8: The technical Claude command

**Files:**
- Create: `commands/keyfarm-maintain.md`

**Interfaces:**
- Produces: the reusable technical command downstream repos copy into `.claude/commands/`. It wraps a functional command file and keeps `task.ts` mirrored.

- [ ] **Step 1: Write `commands/keyfarm-maintain.md`**

````markdown
---
description: Execute a functional browser command against the keyfarm jailed browser while maintaining the mirrored Playwright script.
argument-hint: <functional-command.md> [cookies-dir] [script.ts]
---

# keyfarm-maintain

You maintain a Playwright script (`run(page)`) so it stays a deterministic mirror
of a hand-written **functional command**, while executing that command against
keyfarm's **jailed, stealthed** browser.

**Inputs** (from `$ARGUMENTS`, with defaults):
- functional command file (required) — natural-language browser steps
- cookies dir — default `./cookies`
- target script — default `./task.ts`

**Do this:**

1. **Read** the functional command file. Note its numbered steps and Success criteria.
2. **Ensure a warm profile.** If the cookies dir has no session for the target
   site, tell the user to farm keys first: `nix run .#browser -- <cookies-dir>`,
   log in by hand, close it. Do NOT try to log in via automation (it burns stealth).
3. **Explore live.** With the jailed browser running, drive it (Playwright MCP
   over its CDP endpoint, or by iterating the script) to work out selectors and
   flow for each step. Prefer resilient locators (roles/text) over brittle CSS.
4. **Mirror into the script.** Create or update the target `run(page)` script so
   each functional step maps to a code block prefixed `// step N:` matching the
   functional command's numbering. Keep it minimal — no dead branches.
5. **Verify deterministically.** Close the headful browser (profile is single-lock),
   then run `nix run .#run -- <cookies-dir> <script.ts>`. It must complete and the
   Success criteria must hold. Iterate until green.
6. **Report** the mirror status: which steps are covered, anything the functional
   command left ambiguous, and any stealth caveats hit (Turnstile challenge, etc.).

**Rules:**
- Never weaken the jail or stealth flags to "make it work."
- The functional command is the source of intent; the script is its deterministic
  shadow. If they drift, fix the script, and flag the functional command if a step
  is now wrong.
- Turnstile is not solvable by clicking/vision — rely on the warm profile + patchright.
  If blocked, report it; do not add captcha-solving.
````

```markdown
# keyfarm

Jailed, stealthed browser + AI-maintained Playwright scripts, as a Nix flake.
The technical layer other (functional, website-specific) repos build on.

## Apps
- `nix run .#browser -- <cookies-dir>` — jailed **headful** Chromium for **farming
  keys**: log in by hand; the session persists in `<cookies-dir>`.
- `nix run .#run -- <cookies-dir> <script.ts>` — jailed **headless** replay of a
  `run(page)` script. Deterministic, no AI.
- `nix develop` — dev shell (node, chromium, bubblewrap, patchright).

## Downstream use
Add keyfarm as a flake input and compose an app (see `templates/consumer-flake.nix`):
`keyfarm.lib.mkApp { inherit pkgs; cookiesDir = "./cookies"; script = ./task.ts; }`.
Copy `commands/keyfarm-maintain.md` into your `.claude/commands/` and write a
functional command (`templates/functional-command.md`).

## Design notes
- **Jail:** bubblewrap (fs/process isolation; network shared). Chromium `--no-sandbox`
  inside — bwrap is the sandbox.
- **Stealth:** patchright kills the automation tells. Browser is `pkgs.chromium`
  (overridable, but **never Google Chrome**).
- **Turnstile:** not LLM-solvable; the lever is a warm profile (`cf_clearance`,
  bound to IP+UA+TLS, ~30 min) + patchright + a good IP. Datacenter IPs still get hit.
- See `docs/superpowers/specs/2026-07-29-keyfarm-design.md`.
```
